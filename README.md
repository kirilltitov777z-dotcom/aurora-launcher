# Aurora Launcher 3.0

Домашний экран на Kotlin + Jetpack Compose. Полный редизайн: новые темы, конструктор своей темы, готовые виджеты и декоративный сканер отпечатка.

## Что нового в 3.0

### Шесть тем вместо пяти

| Тема | Характер |
| --- | --- |
| **Стекло** | Матовое стекло с преломлением (Android 13+) |
| **Импульс** | Крупные формы, выразительная typography, пружины |
| **Лайт** | Просто и быстро: без размытия и тяжёлых эффектов |
| **iOS** | Непрерывная маска значков, плотный размытый док, мягкие пружины, спокойные цвета |
| **Nothing** | Монохром, чёткие формы, нулевое размытие и подсветка, короткие переходы |
| **Своя** | Конструктор: имя темы, форма значков, скругления, стекло, фон дока, свечение и характер анимации |

Темы Neon и Aurora удалены. Старые сохранённые настройки этих тем автоматически переводятся на iOS.

### Готовые виджеты

На странице «Темы → Готовые виджеты» один тап собирает нужный стол:

- **Часы HyperOS** — очень крупное время с градиентом, пилюли даты и заряда;
- **Часы Nothing** — точное минималистичное время;
- **Классические часы**, **компактные часы** и **чистый стол**.

### Сканер отпечатка

Декоративный экран блокировки с анимированным датчиком: кольца пульсируют, при касании проходит линия сканирования, затем появляется зелёный контур «распознано» и вызывается реальная блокировка экрана.

- компактный датчик в правом верхнем углу стола (можно выключить в «Жестах»);
- пункт «Сканер» в меню стола и в настройках;
- жест блокировки теперь тоже показывает сканер;
- опциональная вибрация при распознавании.

### Прочее

- Нейтральная палитра иконки приложения: графит + серебро вместо неонового свечения.
- Обновлены обе локали (RU/EN), поиск по настройкам и онбординг.
- Версия 3.0 (код 7).

## Сборка

APK в репозиторий не вкладывается: для сборки нужны JDK 21 и Android SDK 37.

- Локально: `./gradlew assembleRelease`, результат — `app/build/outputs/apk/release/app-release.apk`. Скрипт `./build-apk.sh` дополнительно копирует APK в корень как `AuroraLauncher-3.0.apk`.
- Через GitHub Actions: `.github/workflows/build-apk.yml` собирает APK и публикует его в Release `v3.0`.

## Установка

- Требуется Android 8.1+. Преломление стекла — Android 13+.
- Пакет `com.aurora.launcher`. Если ставите поверх старой сборки с тем же пакетом и другим ключом, сначала удалите её.
- После установки укажите Aurora Launcher как лаунчер по умолчанию.

## Разрешения

Список приложений, доступ к файлам (размытие обоев), установка обоев, будильник, уведомления, доступность (жесты и блокировка), вибрация. Интернета у лаунчера нет.
